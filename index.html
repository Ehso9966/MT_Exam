MT Exam — မြန်မာကျောင်းဆရာ/ဆရာမများအတွက် စာမေးပွဲစာရွက် ဖန်တီးမှု

အခမဲ့ အွန်လိုင်း မေးခွန်းစာရွက် ဖန်တီးမှုကိရိယာ

MT Exam သည် မြန်မာကျောင်းဆရာ/ဆရာမများအတွက် အခမဲ့ browser-based စာမေးပွဲစာရွက် ဖန်တီးကိရိယာတစ်ခုဖြစ်သည်။ လက်ရေးစာများ သို့မဟုတ် ဓာတ်ပုံမှ မေးခွန်းများကို လှပသော format ရှိသည့် ပုံနှိပ်နိုင်သော မေးခွန်းစာရွက်အဖြစ် မိနစ်ပိုင်းအတွင်း ပြောင်းလဲပေးနိုင်သည် — install လုပ်စရာ မလိုပါ။

အခမဲ့ စတင်ဖန်တီးမည် အင်္ဂါရပ်အားလုံး ကြည့်ရန် အသုံးပြုနည်း

အဓိကအင်္ဂါရပ်များ

  • AI OCR — ဓာတ်ပုံမှ မေးခွန်းများကို ထုတ်ယူခြင်း
  • မေးခွန်းအမျိုးအစားများ — MCQ, မှန်/မှား, အတိုဖြေ, အသေးစိတ်ဖြေ, သင်္ချာ
  • KaTeX သင်္ချာ — LaTeX ပုံသေနည်းများ လှပစွာ render
  • စစ်ဆေးမှုစနစ် — အမှတ်၊ နံပါတ်စဉ်၊ မေးခွန်းများ အလိုအလျောက် စစ်ဆေးခြင်း
  • ပုံနှိပ်/PDF — Padauk နှင့် Pyidaungsu မြန်မာဖောင့်များ ပါဝင်သော A4 print stylesheet
  • ကိုယ်ရေးလုံခြုံမှု — သင့် စာမေးပွဲ မေးခွန်းများသည် သင့် browser ထဲတွင်သာ ရှိပြီး မည်သည့်နေရာသို့မျှ upload မလုပ်ပါ

မေးလေ့ရှိသော မေးခွန်းများ

MT Exam ဆိုတာဘာလဲ?

MT Exam သည် မြန်မာကျောင်းဆရာ/ဆရာမများအတွက် အခမဲ့ browser-based စာမေးပွဲစာရွက် ဖန်တီးကိရိယာဖြစ်သည်။ AI OCR၊ သင်္ချာပုံသေနည်းများနှင့် စစ်ဆေးမှုစနစ်များဖြင့် စာမေးပွဲစာရွက်များကို ဖန်တီး၊ ဖော်မတ်ပြုပြင်၊ ပုံနှိပ်နိုင်သည်။

MT Exam အခမဲ့လား?

ဟုတ်ကဲ့။ MT Exam သည် လုံးဝ အခမဲ့ဖြစ်သည်။ AI OCR အင်္ဂါရပ်ကို သုံးလိုပါက ကိုယ်ပိုင် B.AI API သော့တစ်ခုသာ လိုအပ်ပါသည်။

ဘာမှ တပ်ဆင်ရန် လိုအပ်ပါသလား?

မလိုပါ။ MT Exam သည် သင့် browser ထဲတွင်သာ အလုပ်လုပ်ပါသည်။ ဝဘ်ဆိုက်ကို ဖွင့်ပြီး စာမေးပွဲစာရွက် စတင်ဖန်တီးနိုင်ပါသည်။

သင်္ချာပုံသေနည်းများ ရိုက်ထည့်နိုင်ပါသလား?

ရနိုင်ပါသည်။ MT Exam သည် LaTeX သင်္ချာပုံသေနည်းများအတွက် KaTeX rendering ကို ထောက်ပံ့ပေးပါသည်။ သင့်မေးခွန်းများထဲတွင် equations များ တိုက်ရိုက်ထည့်နိုင်ပါသည်။

MT Exam သည် မြန်မာဘာသာဖြင့် အလုပ်လုပ်ပါသလား?

အလုပ်လုပ်ပါသည်။ MT Exam သည် Padauk နှင့် Pyidaungsu ဖောင့်များ၊ မြန်မာနံပါတ်ပုံစံများ အပါအဝင် ပြည့်စုံသော မြန်မာဘာသာစကား ထောက်ပံ့မှုရှိပါသည်။
